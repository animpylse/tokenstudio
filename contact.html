Official contact routes

Contact Token Studio

Questions, bug reports, collaborations, and security disclosures each have a clear destination. Token Studio support will never ask for a seed phrase, private key, or wallet authentication credential.

SUPPORT

App questions and bug reports

Join the official Discord for unexpected behavior, transaction classification issues, or questions about using a feature. Include the app version, device, affected workflow, what happened, and what you expected. Share a public transaction signature only when it is relevant and safe to do so.

Open Discord
CONNECT

Product, media, and partnerships

Contact the creator through the official X account for ecosystem collaboration, interviews, demonstrations, product discussions, or partnership proposals. Include who you represent, what you are proposing, and the links needed to understand the request.

Contact @impylse
SECURITY

Report a security concern privately

Ask for @admin in the official Discord without posting exploit details in a public channel. Describe the affected workflow, reproducible conditions, and potential impact. Do not access wallets, accounts, or data you do not control while investigating a report.

Review the security model
Remember: Token Studio cannot access private keys or sign on a user's behalf. Support cannot reverse confirmed Solana transactions or alter public on-chain records. Never send a seed phrase, private key, one-time code, or remote-access credential to anyone claiming to represent Token Studio.
