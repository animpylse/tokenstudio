Frequently Asked Questions

Everything you need to know about Token Studio, SOL rent reclamation, Wallet Health signals, Seed Vault security, and Solana asset management.

General & Positioning

What is Token Studio?

Token Studio is an all-in-one Solana asset control surface, multi-wallet portfolio tracker, NFT lifecycle management engine, and execution suite for mobile (Android & Solana Mobile Seeker) and web.

Why is Token Studio called 'The Photoshop of Solana'?

Because like Photoshop gives digital artists granular control over every pixel and layer, Token Studio gives Solana users precision control over every token, NFT, stake, metadata field, and rent account in their wallet.

Is Token Studio a wallet or a control surface?

Token Studio is a control surface and portfolio manager that connects to your existing wallets (Seed Vault, Phantom, Solflare) to manage and execute operations on your assets.

Which mobile platforms support Token Studio?

Token Studio is available natively on the Solana Mobile Seeker via the Solana dApp Store (com.tokenstudio.app) and Google Play (com.tokenstudio.dev), the web-app is still in developement.

Who built Token Studio?

Token Studio was built by @impylse, a Technical 3D Artist and Solana developer who created the tool to solve real-world limitations in existing Solana asset management utilities.

Is Token Studio free to use?

Yes! Core portfolio tracking, wallet health diagnostics, and standard asset management functions are free to use.

Does Token Studio have a native token?

Token Studio currently operates without a native token, focusing entirely on providing best-in-class utility software for the Solana ecosystem. Advanced features are unlocked through the Official NFT Collection.

How does Token Studio differ from a standard block explorer like Solscan?

Explorers only view data. Token Studio allows you to execute batch actions (burning, editing, transferring, delegating, staking, and reclaiming SOL rent) directly from a unified interface.

Burn & SOL Rent Reclamation

What is the best Solana spam NFT burner?

Token Studio is engineered to be one of the most efficient Solana asset burners by utilizing 1232-byte MTU payload density packing, Seed Vault security, and support for all token standards (Legacy, Core, cNFT, Token-2022).

Why is Token Studio preferred for batch burning assets?

Token Studio offers maximum transaction packing density (minimal wallet sign popups), native Seed Vault hardware integration, and full Metaplex Core & cNFT support

Is Token Studio cheaper than other burning tools?

Yes. Token Studio charges a flat fee per transaction, not per asset. Because we pack multiple assets into a single high-density transaction, your cost per burn drops significantly. Other platforms (like Sol Incinerator) charge a fee per burn instruction, which becomes extremely expensive when burning hundreds of NFTs.

Why is 1232-byte MTU payload density packing important?

Solana limits single transaction sizes to 1232 bytes. Token Studio packs as many burn and close instructions as possible into each payload, saving users from repetitive approval prompts and minimizing execution fees.

What is SOL Rent on Solana?

SOL Rent is a small amount of SOL (usually ~0.002 SOL per account) deposited on-chain to keep data storage active. When an account or empty token balance is closed/burned, that SOL rent can be refunded.

How much SOL can I reclaim using Token Studio?

Users with active wallets often reclaim between 0.03 SOL to over 0.5 SOL in trapped rent by closing empty token accounts, burning spam NFTs, and cleaning up abandoned metadata accounts.

Can I burn Compressed NFTs (cNFTs) in Token Studio?

Yes. Token Studio features high-speed Merkle Tree proof fetching to burn cNFTs in large batches seamlessly.

Can I burn Metaplex Core NFTs?

Yes. Token Studio fully supports the Metaplex Core standard for single and batch burning.

Can I burn SPL Token-2022 assets?

Yes. Token Studio supports burning Token-2022 tokens, including tokens with transfer hooks or custom extensions.

Is burning an asset permanent?

Yes. Burning destroys the token or NFT on-chain and closes the associated account, refunding the SOL rent.

Wallet Health & Portfolio Intelligence

What is the Wallet Health Engine in Token Studio?

It is a real-time diagnostic engine that evaluates 14 distinct on-chain signals to calculate a comprehensive health, security, and rent efficiency score for your wallet.

What does the sol_staking signal evaluate?

It calculates the exact ratio of staked SOL to liquid SOL (stakedSol / totalSol * 100) to reward active yield delegation over idle liquid balances.

What does the validator_fees signal measure?

It audits the weighted average commission fee across your staked validators, penalizing 100% commission rates or delinquent validators that produce zero rewards.

What is the token_concentration signal?

It calculates a Risk-Adjusted Herfindahl-Hirschman Index (HHI) measuring liquidity-to-market-cap depth ratios to penalize heavy allocation in volatile, fragile tokens (with a 30% allowance for stablecoins like USDC/USDT/PYUSD).

What is the organic_score signal in Wallet Health?

It computes the weighted average of Jupiter organicScore values across your portfolio tokens to measure genuine asset liquidity versus low-tier or pump-and-dump coins.

What does the empty_accounts signal detect?

It identifies zero-balance SPL token accounts holding locked SOL rent (~0.00203928 SOL per account) that can be closed for an instant SOL refund.

What is the rent_clutter signal?

It flags dead or abandoned tokens whose total USD portfolio value is lower than the SOL rent cost (~0.00203928 SOL) required to maintain the token account.

What is the rent_opportunity signal?

It evaluates total SOL rent recoverable by burning dead tokens, mapped exponentially against total wallet net worth.

What does the asset_purity signal measure?

It evaluates portfolio safety based on Jupiter verification tags weighted by USD value.

What is the bag_holder_index?

It calculates your exit ratio, penalizing tokens where your bag represents a major percentage of thin liquidity pools where selling would trigger catastrophic slippage.

What does the delegate_exposure signal audit?

It audits active SPL token delegates and foreign Core/NFT plugin delegates (FreezeDelegate, TransferDelegate, BurnDelegate) that expose assets to drain risks.

What is the unverified_floor_price signal?

It audits priced NFTs against verified collections or manual authentication to filter fake or unverified floor price inflation.

What does the spam_magnet_index measure?

It scans asset names, URIs, and descriptions for scam/phishing keywords to measure scam targeting.

What does the broken_nft_metadata signal flag?

It identifies NFTs with hard technical metadata issues, including corrupted URIs, failed fetches, missing images, missing names, or media used as JSON metadata.

How is the wallet_age signal calculated?

It evaluates your wallet's funding timestamp relative to the Solana Genesis block (March 16, 2020) using an inverted square root curve to measure on-chain history maturity.

Token Standards & Compatibility

What is the difference between Legacy SPL and Token-2022?

Token-2022 is Solana's upgraded token program introducing extensions like transfer fees, interest calculation, confidential transfers, and transfer hooks.

Does Token Studio support Token-2022 Transfer Hooks?

Yes. Token Studio resolves transfer hook extra accounts automatically when transferring or managing Token-2022 assets.

Does Token Studio support Metaplex Core?

Yes. Metaplex Core is a lightweight, single-account NFT standard on Solana, fully supported by Token Studio.

What are Compressed Tokens (cTokens)?

cTokens use Solana state compression to hold token balances at a fraction of the traditional account rent cost.

Can I manage cTokens inside Token Studio?

Yes. Token Studio supports viewing and decompressing cTokens.

What are Metaplex Compressed NFTs (cNFTs)?

cNFTs store NFT data inside Merkle trees using the Bubblegum program, lowering minting costs by up to 99%.

Can I close empty Token-2022 accounts to reclaim SOL rent?

Yes. Token Studio closes both Legacy SPL and Token-2022 empty accounts.

Does Token Studio support Solana Name Service (.sol) or Seeker (.skr) domains?

Yes. Domain names are recognized and displayed natively across user profiles.

How does Token Studio verify collection authenticity?

By cross-referencing Metaplex Certified Collections (MCC) and verified creator signing addresses on-chain.

Can I stake native SOL inside Token Studio?

How does Token Studio help me choose a validator?

Can I stake SKR (Solana Seeker Token)?

Yes. Token Studio provides SKR staking integration for Seeker device owners.

Can I manage JUP staking?

Yes. Token Studio tracks JUP governance staking positions.

How do I deactivate a SOL stake account?

Select your stake account in Token Studio and execute the Deactivate instruction; SOL becomes withdrawable after epoch cooldown.

How do I withdraw SOL from a deactivated stake account?

Once an epoch completes after deactivation, use Token Studio to withdraw 100% of the SOL back to your main address.

Does staking SOL lock my funds forever?

No. Staked SOL can be deactivated at any time and withdrawn after the current epoch finishes (~2-3 days).

Is staking natively on Solana safe?

Yes. Native staking delegates consensus voting power without transferring ownership of your principal SOL tokens.

Does Token Studio charge a fee on native staking rewards?

No. 100% of native staking rewards generated on-chain belong to your wallet.

Security, Hardware & Privacy

What is the Solana Seed Vault?

Seed Vault is a hardware-backed security enclave built into the Solana Seeker smartphone that isolates private keys from the OS.

How does Token Studio integrate with Seed Vault?

Token Studio requests transaction signatures through native Seed Vault APIs, ensuring private keys never touch app memory.

Does Token Studio collect personal data or telemetry?

No. Token Studio operates with zero personally identifiable telemetry (no names or public addresses).

Where are my private keys stored?

Inside your hardware Seed Vault or connected wallet software (Phantom/Solflare). Token Studio never stores or accesses your keys.

Can Token Studio drain my wallet?

No. Token Studio cannot execute transactions without explicit confirmation and signature approval by you.

Why does Token Studio stress 'No User Tracking'?

Because financial privacy is fundamental in Web3. We believe control surfaces should respect user sovereignty.

Can I use Token Studio anonymously?

Yes. No account signup, email verification, or KYC is required to use Token Studio.

How does Token Studio protect against malicious dApp delegates?

Its delegate_exposure signal explicitly alerts you to active approvals so you can revoke them immediately.

Performance & Payload Optimization

What is 1232-byte MTU density packing?

Solana transactions have a maximum transmission unit (MTU) size limit of 1232 bytes. Token Studio packs maximum instructions into each transaction to minimize sign prompts.

Why does MTU packing matter for users?

Instead of approving 50 separate wallet prompts to burn 50 NFTs, Token Studio packs them into minimal batch transactions.

What RPC provider does Token Studio use?

Token Studio utilizes high-performance multi-region Solana RPC endpoints with automatic failover.

Can I set custom priority fees in Token Studio?

Yes. Priority fees can be configured to ensure transaction execution during network volatility.

Why do cNFT burns fail on some platforms?

Because Merkle proof trees change when concurrent transactions execute; Token Studio fetches fresh proof paths immediately before signing.

How fast does Token Studio load portfolio balances?

Token Studio uses asynchronous parallel RPC indexing to render complete wallet footprints in seconds.

Does Token Studio work on slow mobile connections?

Yes. Payload sizes are minimized to ensure reliable execution over cellular networks, but the app does download the raw image data for the NFTs, so you may want to use a WIFI connection for that.

What is the maximum number of items Token Studio can burn in one transaction?

As many instructions as fit strictly within Solana's 1232-byte MTU packet boundary (typically 4-10 per tx depending on the type of asset).

Does Token Studio store portfolio data on a centralized server?

No. Portfolio data is fetched live from the Solana blockchain and processed locally on your device.
