Solana wallet questions

Can Token Studio replace a Solana block explorer?

For everyday wallet investigation, it can remove much of the need to leave the app. Token Explorer and Flight History expose assets, accounts, programs, instructions, signers, fees, and balance changes. External explorers remain available for independent verification.

Does Token Studio need my seed phrase or private key?

No. Token Studio cannot access a seed phrase or private key, even if it wanted to, because those credentials remain protected by the connected wallet. Read-only exploration needs only a public Solana address and cannot sign transactions.

Why might the displayed portfolio value be incomplete?

Some tokens have no dependable market price, some NFT floors are unverified, and experimental external positions can be incomplete. Token Studio leaves unreliable values out instead of presenting them as certain.

How many wallets can I track?

Standard users can add one portfolio address alongside the connected wallet. Official Token Studio NFT collectors can maintain up to 16 portfolio addresses.

Is the Wallet dashboard free?

Portfolio inspection, search, Wallet Health, and read-only exploration have no Token Studio service fee. Some signed actions launched from the wallet have specific fees, which are shown before the transaction and documented on the Fees page.
