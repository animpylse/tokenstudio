Changelog & Release History

Complete chronological record of features, Perf enhancements, and bug fixes across all Token Studio releases.

0.19.242-beta August 17, 2026
  • Feature
    Domain Resolver: Added a Domain Resolver in the Favorites Address Browser. You can now send to .sol and .skr domains. I chose this implementation method because I believe it is safer than just typing a domain name and not seeing the actual address. Additionally there is now a safety check running every 10 minutes before you send any transaction to make sure the domain is still pointing to the address you are sending to, since domains can be burned, transfered, or expire. In combination with the other new feature, that should make it a lot less likely to accidentally send a transaction to the wrong address. Not sure why wallets are not deploying safety measures like that, but I think it's a gamechanger.
  • Feature
    Receipts: Added Receipts for safer transfers. Successful sends/transfers are now recorded per favorite address, with clear familiarity indicators and an extra confirmation prompt before sending or delegating to an address used fewer than two times.
  • Perf
    Favorites Separation: Favorites and Portfolio Addresses are now separate. Favorites now support up to 256 addresses for everyone. Existing Portfolio Addresses must be re-added to the new Portfolio list in the Dashboard.
  • Perf
    Significantly Improved the application's responsiveness during heavy operations.
  • Perf
    Priority Fees: Priority Fees Off state is now Min. Min applies a virtually insignificant priority fee across transactions to improve reliability during network congestion while keeping the extra cost close to zero. I will be adding a dynamic priority fee option at some point, but for now this should do.
  • Fix
    Improved NFT mint transaction confirmation handling. Legacy NFT mints no longer show an unrelated error when network confirmation is delayed.
  • UX
    Various UI/UX improvements.
  • Fix
    Various bug fixes.
