Batch Transfers, Burns & Swaps

Low-Fee Solana Token Swaps

Swap Solana tokens using quotes from the Jupiter liquidity aggregator. Token Studio builds each swap directly to offer fees two to five times lower than standard Jupiter interfaces. Token Time Vault collectors pay no Token Studio swap fee.

Multi-Select Tool

Select all, deselect all, invert selection, or manually pick mixed assets to instantly add to a burn/transfer queue or hide them.

Batch Token and NFT Burner

Burn mixed batches of tokens, NFTs, and compressed NFTs with one click to clean up your wallet and recover SOL rent. Solana V1 transactions support up to 4,096 bytes, allowing more assets and account actions to fit into each transaction.

Complete Wallet Transfer

Faster Batch Transactions
