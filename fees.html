How estimated SOL recovery works

Token Studio estimates recoverable SOL from each account's data length and current Solana rent requirement. The percentage fee applies only to the SOL expected to be recovered. It never uses the market value of a token or NFT.

See how recovery coverage changes the real result in our Sol Incinerator alternative comparison, which publishes the decoded payloads and simulated wallet returns.

  • Known recovery: the fee is 0.8% of the estimated recovered SOL.
  • Unknown recovery: if Token Studio cannot produce an estimate, the fee is 0 SOL.
  • Burn safety cap: the total Token Studio burn fee cannot exceed 0.01 SOL in one transaction, protecting users if rent is misestimated or an account contains additional SOL.
  • Atomic charging: the service-fee transfer is the final instruction in the same transaction. If a transaction fails or is cancelled before submission, no Token Studio service fee is collected.

Fungible Token Burn Policy

When a Fungible Token balance is worth more than $0.01, Token Studio may transfer the remaining balance to its fee wallet before closing the token account instead of burning it. The transferred token balance is part of the Token Studio fee structure for fungible token burns.

If the Token Studio fee wallet does not already have an account for that token, creating one may use some of the otherwise recoverable rent. The in-app recovery estimator accounts for this and shows 0 SOL estimated recovery in this case. Users who accidentally burn valuable tokens can contact Token Studio on Discord within 30 days and tag @admin to request their return.
