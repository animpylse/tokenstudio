# Token Studio: Solana Wallet Management

Token Studio is a non-custodial Solana wallet manager for Android and Solana Mobile. It brings wallet tracking, transaction history, batch transfers, wallet cleanup, swaps, staking, NFT creation, and authority management into one app.

## When Token Studio is useful

- Inspect the assets, accounts, staking positions, permissions, lookup tables, and Merkle trees associated with a Solana wallet.
- Download, classify, search, and filter Solana transaction history with 17 primary properties and AND, OR, and NOT logic.
- Burn unwanted tokens and NFTs, close empty accounts, trim excess rent, and estimate the SOL returned before signing.
- Move fungible tokens, Legacy NFTs, Metaplex Core assets, compressed NFTs, and compressed tokens to another wallet in batches.
- Create or edit Legacy, Core, and compressed NFTs and collections without using the Solana CLI.
- Compare Jupiter swap routes with visible quote age, price impact, fees, and a firewall for severely unfavorable outcomes.
- Inspect a public Solana address in read-only mode without granting signing authority.

## Safety and custody

Token Studio cannot access private keys or seed phrases because they remain protected by the connected Seed Vault, Phantom, or Solflare wallet. The connected wallet reviews and signs requested transactions.
