Optimized Swaps

Know the Route Before Your Wallet Signs It

Token Studio uses Jupiter liquidity while exposing the price impact, value change, costs, route, account complexity, quote age, and safety boundaries behind each Solana token swap.

TL;DR

Swap fees range from 0% to 0.04% for established pairs and 0.1% for eligible newly pooled tokens. A projected value loss above 10% requires confirmation, 20% or more is blocked, and Token Time Vault collectors pay no Token Studio service fee. Because every eligible swap produces a measurable saving, Token Time Vault NFTs have a quantifiable economic value that can grow with the holder's swap volume.

Two execution modes, selected automatically

Token Studio chooses the mode from the selected token pair. The user does not need to understand or manually select the execution path.

EDGE

Built locally by Token Studio

When the pair is supported by EDGE, Token Studio constructs the transaction locally from the Jupiter route, adds its safety instrumentation, and enables stacked execution.

ULTRA

Automatic fallback for other pairs

If either side of the pair is not supported by EDGE, Token Studio automatically uses Jupiter ULTRA for execution.

A firewall between a bad quote and your signature

Warnings are based on the projected change in wallet value, not only the route's displayed price impact.

>10%

Projected wallet-value loss requires a separate, explicit confirmation before execution can continue.

≥20%

The swap is terminated. Confirmation cannot override the hard-stop threshold.

3–9s

Quotes move from fresh to aging and then stale. A stale quote expires rather than executing silently.

1% / 4%

Destination-value changes receive warning emphasis above 1% and a stronger warning above 4%.

Solana swap questions

Does Token Studio find its own liquidity?

No. Token Studio uses routes from Jupiter's liquidity infrastructure. Its own contribution is the execution interface, route controls, fee logic, local EDGE builder, stacking, and safety firewall.

Why would I lower transaction complexity?

A simpler route can be easier for a wallet to simulate and sign. The tradeoff is that excluding account-heavy routes may reduce output quality or leave no available route.

Can I swap from a read-only wallet?

No. Read-only mode can inspect public wallet data but cannot sign a token swap or any other transaction.

Are stacked swaps one atomic transaction?

No. Every transaction is atomic internally, but a stack contains multiple independent transactions. One transaction can fail without reversing a different transaction that already succeeded.

Are Token Studio collectors charged swap fees?

No. Token Time Vault collectors pay zero Token Studio service fees across the entire app. Network, liquidity-pool, Jupiter, rent, and market costs can still apply.
